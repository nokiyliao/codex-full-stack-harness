Source verification starts no model or service. Existing component test/build evidence is reused only for matching source. Runtime db/, trace-evidence/, caches, private config and raw benchmark logs are not published.

The current source also fixes host generation alias drift: admitted script, contract and helper bytes remain bound to a physical generation while a successor starts. Exact previously emitted dispatch records can explain cross-release delivery differences; they do not prove execution or grant permissions. Execution and observation keep their own strict checks.

Compact final-acceptance shorthand derives defaults for intent, ordinary and shared/delta batch members from their existing read grants. It does not expand write or execution authority; host admission and identity checks remain unchanged.

Typed adapter intake validation rejections stay in the native tool loop as correctable diagnostics, without starting the host or worker. A rejection is not worker success or a permission grant; the caller must correct the rejected input under the original authorization, and unrelated execution and identity failures retain their boundaries.

Cross-generation observation recognizes exact previously emitted dispatches only with paired running native metadata and the original handle. Emission alone is not execution evidence; observation grants no host launch, new session or additional permissions, and never replays the original command.

Compact multi-worker expansion no longer charges copied shared context against a single argv-sized aggregate. The original transport/reference limits remain, and expanded worker requests, the final verifier and batch metadata are bounded separately, including after verifier-catalog expansion. Per-worker admission, request identity, original recovery and the configured concurrency ceiling remain controlling. Deterministic fixtures cover 20-member compact expansion and unchanged per-member preparation/recovery; this is not a claim that 20 live models were launched or that latency/token savings were measured.
